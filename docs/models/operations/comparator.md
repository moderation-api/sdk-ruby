# Comparator

Flag images that contain "at least" or "fewer than" the configured number of faces. Defaults to at_least.

## Example Usage

```ruby
require "moderation_api"

value = Comparator::AT_LEAST
```


## Values

| Name         | Value        |
| ------------ | ------------ |
| `AT_LEAST`   | at_least     |
| `FEWER_THAN` | fewer_than   |
